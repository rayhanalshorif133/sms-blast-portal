POST /api/v3/sms/send

Send single or bulk messages to valid mobile numbers. Supports text and unicode.

Parameters

Field Type Required Description
api_key String Yes Your unique API Key
sender_id String Yes Approved Brand Name or ID
message String Yes Content of the SMS
mobile String Yes Number (e.g. 88017...) 
<?php
$url = "https://api.smsblast.com/api/v3/sms/send";
$data = [
    "api_key" => "YOUR_API_KEY",
    "sender_id" => "SmsBlast",
    "message" => "Hello World!",
    "mobile" => "8801712345678"
];
$ch = curl_init($url);
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);
echo $response;
?>
GET /api/v3/balance

Retrieve your current account balance and currency.

Parameters

Field Type Required Description
api_key String Yes Your unique API Key 
<?php
$api_key = "YOUR_API_KEY";
$url = "https://api.smsblast.com/api/v3/balance?api_key=" . $api_key;

$response = file_get_contents($url);
echo $response;
?>
GET /api/v3/sms/status

Check the delivery status of a specific message ID.

Parameters

Field Type Required Description
api_key String Yes Your unique API Key
message_id String Yes The ID received when sending 
<?php
$api_key = "YOUR_API_KEY";
$msg_id = "MSG-102938";
$url = "https://api.smsblast.com/api/v3/sms/status?api_key=$api_key&message_id=$msg_id";

$response = file_get_contents($url);
echo $response;
?>
